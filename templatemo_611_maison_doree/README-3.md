# Marie de Valois — Fine Gold Jewelry Website

## Overview

Marie de Valois is a responsive luxury jewelry website created as a static HTML/CSS website. It presents a fine gold jewelry atelier, its collections, craftsmanship, brand story, testimonials, and appointment request form.

## Features

- Luxury jewelry homepage design
- Responsive layout for desktop and mobile screens
- Desktop and mobile navigation
- Hero section with jewelry images
- Featured jewelry piece
- Jewelry collection showcase
- Brand story / heritage section
- Craftsmanship section with statistics
- Customer testimonials
- Atelier contact information
- Appointment request form
- Footer with social-media links
- Google Fonts typography

## How to Run

1. Keep `index.html`, the CSS file, and the `images` folder in the same project directory.
2. Open `index.html` in a web browser.
3. No server or database is required for the basic website.

## Main Sections

### Header
Contains the Marie de Valois logo, navigation links, and a "Book Appointment" call-to-action.

### Hero
Introduces the jewelry brand with the headline:

> Where Gold Becomes Art

It includes featured jewelry images and collection information.

### Featured Piece
Highlights the Aurora Pendant, including its material, weight, chain length, description, and price.

### Collections
Displays jewelry categories including:

- Bridal
- Everyday Elegance
- Statement
- Heritage
- Men's Collection

### Our Story
Describes the history and heritage of the jewelry atelier.

### Craftsmanship
Explains the jewelry-making process and highlights the years of experience, master artisans, and pieces created.

### Testimonials
Displays customer reviews and customer information.

### Contact
Provides atelier information, opening hours, telephone details, and an appointment request form.
